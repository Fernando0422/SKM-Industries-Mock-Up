# SKM Industries: Website Concept

A design concept for the SKM Industries website, prepared by [Prime AI Consultants](https://www.primeaiconsultants.com).

Built entirely from SKM's own public material: their published capabilities, certifications, portfolio photography, and the October 2023 CNC West Magazine feature.

## Pages

- `index.html` home
- `capabilities.html` machine shop, automation, paperless production system
- `portfolio.html` filterable gallery by industry
- `quality.html` AS9100D certification and quality system
- `company.html` history, founder story, automation
- `news.html` press and the Caltech LIGO work
- `suppliers.html` supplier terms
- `contact.html` quote request

## Viewing it

Open `index.html`, or serve the folder:

```bash
python3 -m http.server 8000
```

Static HTML, CSS and a small amount of JavaScript. No build step, no dependencies.
